# Tech Transfer Dashboard

## Goal
Build a modern AI-powered dashboard for my company's technology transfer office.

## Users
- Inventors
- Innovation Team (tech transfer office)
- Executive Team
- 

## Core Features
- Patent portfolio overview
- Invention disclosure tracker
- Invention Disclousre conversational fill out form 
- Inventor profiles
- Startup/company tracker
- Licensing pipeline
- Market research summaries
- Competitive intelligence
- Executive reporting dashboard

## Version 1 Scope
Start with a beautiful static dashboard using fake data.
Do not add authentication, databases, or payments yet.

## Sidebar
Sidebar with clickable buttons in the following order:
- Overview
- Invention Disclosure
- Licensing Center
- Reports
- Intellectual Property Directory

## Design Style
Modern, clean, professional, similar to Linear, Notion, or Stripe dashboards.

## Preferred Stack
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide icons
- Recharts

## Innovation Pipeline Visualization
On the overview page, I'm hoping to have a visual of what the innovation team is working on. That means I want to see the multiple steps as part of the innovation timeline with a few key things. 

- A spectrum with different steps going from left to right: 1. Inventor fills out invention disclosure form detailing technology, 2. innovation team does a thorough assessment focus on three things: a. strategic fit, b. market potential, c. IP and patent landscape. 3. Innovation team will present findings to inventors and the executive team.
